# FLOOR ZERO — Combat Feel Test

Browser-first Godot 4 prototype for a dense, forward-driving action game.

## Open

1. Open Godot Project Manager.
2. Click **Import**.
3. Choose `project.godot` in this folder.
4. Open the project and press **F6/F5**.

## Controls

- `WASD`: move
- Mouse: look
- Left mouse: automatic fire
- Right mouse: aim
- `E`: open the breach door once near it

## What to evaluate

1. Is entering the first room immediately satisfying?
2. When aiming against a rail/table edge, does the `MOUNT` message feel clear and rewarding?
3. Does opening the door create an urge to move forward, rather than pause or manage a system?

This first slice deliberately has no inventory, progression, missions, or weapon menu. It tests only movement, hitscan feedback, a readable mounting advantage, and forward pressure.
